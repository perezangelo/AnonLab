La AnonLab SOC Dashboard è una piattaforma avanzata progettata per offrire una visione completa e centralizzata delle attività di sicurezza informatica, threat intelligence e monitoraggio tecnico.

  • Frontend statico su GitHub Pages
  • Backend dinamico su AlterVista (PHP + MySQL)
  • Widget interattivi in JavaScript
  • API personalizzate per dati real‑time
  • Stile cyber‑neon per una visualizzazione moderna

Questa pagina spiega nel dettaglio come funziona la dashboard, quali componenti contiene e come viene utilizzata per analisi tecniche, monitoraggio e threat intelligence.

Architettura della Dashboard

Frontend: GitHub Pages

Il frontend è ospitato su GitHub Pages, ideale per velocità, affidabilità e assenza di costi.

  • blocchi neon
  • widget interattivi
  • grafici
  • radar delle minacce
  • pannelli informativi

Backend: AlterVista (PHP + MySQL)

AlterVista gestisce API, database, log tecnici e dati dinamici.

https://angelonline.altervista.org/api/get-threats.php
https://angelonline.altervista.org/api/system-status.php
https://angelonline.altervista.org/api/radar-data.php

Questa separazione garantisce sicurezza, modularità e performance.

Widget della SOC Dashboard

System Status

Monitoraggio uptime, latenza, servizi critici.

Threat Radar

Visualizzazione minacce attive, categorie, severità.

IOC Intelligence

IP malevoli, hash, domini, URL sospetti.

CVE Monitor

Vulnerabilità critiche, CVSS, exploit pubblici.

Ransomware Feed

Gruppi attivi, leak recenti, infrastrutture note.
