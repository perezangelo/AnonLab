OSINT Investigation Case Study — AnonLab

Questo caso di studio OSINT mostra come raccogliere, analizzare, verificare e correlare informazioni pubbliche per ricostruire attività sospette. L’indagine è completamente legale e basata su fonti pubbliche.

Fonti OSINT investigative

  • 🔍 Bellingcat Investigations
  • 🔍 Graphika Network Analysis
  • 🔍 CIRCL Passive DNS

Scenario

Un dominio sospetto viene segnalato da un feed di threat intelligence. Obiettivo: determinare se il dominio è parte di un’infrastruttura malevola.

Fonti per analisi domini

  • 🌐 DNSTwister — Domain Variants
  • 🌐 URLScan.io — Domain Scanning
  • 🌐 crt.sh — Certificate Transparency

Fase 1 — Raccolta

Strumenti utilizzati:

  • WHOIS
  • DNSDumpster
  • SecurityTrails
  • Google Dorking
  • Shodan

Risultati:

  • registrazione recente
  • IP condiviso con altri domini sospetti
  • server con porte aperte non standard

Fonti OSINT tecniche

  • 🛠️ GreyNoise Visualizer
  • 🛠️ Onyphe Cyber Defense Search
  • 🛠️ Netlas — Internet Scanning

Fase 2 — Analisi

Correlazione dei dati:

  • IP utilizzato in precedenti campagne phishing
  • certificato SSL self‑signed
  • hosting su VPS low‑cost

Fonti di correlazione

  • 📡 AbuseIPDB — IP Reputation
  • 📡 VirusTotal — Domain/IP Analysis
  • 📡 ThreatMiner — IOC Correlation

Fase 3 — Verifica

Verifica tramite fonti indipendenti:

  • feed OSINT pubblici
  • report di sicurezza
  • analisi passive DNS

Fonti di verifica

  • 🔎 PhishTank — Phishing Verification
  • 🔎 CheckPhish — URL Risk Analysis
  • 🔎 OpenINTEL — DNS Intelligence

Fase 4 — Reporting

Il dominio viene classificato come:

  • High Risk
  • probabile infrastruttura phishing
  • correlato a campagne precedenti

Fonti per reporting

  • 📝 MITRE Publications
  • 📝 ENISA Cybersecurity Reports

Conclusione

Questo caso di studio mostra come l’OSINT possa identificare infrastrutture malevole senza violare alcun sistema. AnonLab integra tecniche OSINT nella dashboard SOC per migliorare la threat intelligence.
