La AnonLab SOC Dashboard è una piattaforma avanzata progettata per offrire una visione completa e centralizzata delle attività di sicurezza informatica, threat intelligence e monitoraggio tecnico. È costruita con un’architettura ibrida che combina:

  • Frontend statico su GitHub Pages
  • Backend dinamico su AlterVista (PHP + MySQL)
  • Widget interattivi in JavaScript
  • API personalizzate per dati real‑time
  • Stile cyber‑neon per una visualizzazione moderna

Questa pagina spiega nel dettaglio come funziona la dashboard, quali componenti contiene e come viene utilizzata per analisi tecniche, monitoraggio e threat intelligence.

Architettura della Dashboard

Frontend: GitHub Pages

Il frontend della dashboard è ospitato su GitHub Pages, una soluzione ideale per:

  • velocità di caricamento
  • affidabilità
  • assenza di costi
  • perfetta integrazione con HTML, CSS e JavaScript

La parte visiva della dashboard include:

  • blocchi neon
  • widget interattivi
  • grafici
  • radar delle minacce
  • pannelli informativi

Backend: AlterVista (PHP + MySQL)

AlterVista viene utilizzato come backend per:

  • API PHP
  • database MySQL
  • gestione dei dati dinamici
  • log tecnici
  • endpoint per i widget

Il sito anonlab.it punta a GitHub Pages, mentre AlterVista fornisce i dati tramite API come: 

https://angelonline.altervista.org/api/get-threats.php
https://angelonline.altervista.org/api/system-status.php
https://angelonline.altervista.org/api/radar-data.php

Questa separazione garantisce sicurezza, modularità e performance.

Componenti principali della SOC Dashboard

1. System Status Widget

Mostra lo stato dei sistemi monitorati: uptime, risorse, servizi attivi, API funzionanti. Utilizza chiamate AJAX verso AlterVista per ottenere dati aggiornati.

2. Threat Monitor

Analizza indicatori di compromissione (IOC), vulnerabilità recenti (CVE), feed di minacce e trend globali. Il widget è progettato per essere leggero ma informativo.

3. Radar delle Minacce

Il radar è uno dei componenti più avanzati della dashboard. Visualizza:

  • livello di rischio
  • categoria della minaccia
  • origine
  • trend temporale

Il rendering è gestito da radar.js, un modulo personalizzato che interpreta i dati provenienti dal backend AlterVista.

4. OSINT Tools Panel

Una sezione dedicata agli strumenti OSINT integrati nella dashboard, con link rapidi e funzioni utili per investigazioni digitali.

5. Download Center

Un pannello che raccoglie software utili per cybersecurity, con link diretti e blocchi neon personalizzati.

6. Log Viewer

Permette di visualizzare log tecnici provenienti dal backend, utili per analisi e debugging.

Integrazione con API e Backend

La dashboard comunica con AlterVista tramite API PHP. Ogni widget effettua richieste come: 

fetch("https://angelonline.altervista.org/api/system-status.php")
  .then(r => r.json())
  .then(data => updateWidget(data));

Questa architettura permette:

  • aggiornamenti real‑time
  • separazione tra frontend e backend
  • scalabilità
  • sicurezza
  • manutenzione semplificata

Design Cyber‑Neon

La dashboard utilizza uno stile cyber‑neon con:

  • colori blu elettrico
  • glow effects
  • pannelli scuri
  • bordo luminoso
  • animazioni leggere

Questo stile non è solo estetico: migliora la leggibilità e rende la dashboard moderna e professionale.

Funzioni avanzate

Alerting

Il sistema può generare alert visivi quando rileva anomalie o minacce elevate.

Auto‑refresh

I widget possono aggiornarsi automaticamente ogni pochi secondi.

Data normalization

I dati provenienti dal backend vengono normalizzati per garantire coerenza e leggibilità.

Modularità

Ogni componente può essere aggiornato o sostituito senza modificare l’intera dashboard.

Conclusione

La AnonLab SOC Dashboard è una piattaforma completa, moderna e altamente personalizzata per analisi tecniche, threat intelligence e monitoraggio. La combinazione GitHub Pages + AlterVista + API + widget neon crea un ecosistema potente, veloce e professionale.
